# M4.2 Group policy gate

`GroupPolicyGate` is a deterministic, process-local controller that sees the
global `Objective` and the complete event history. Agents continue to receive
only their `TaskContext`; the gate never changes that local view. It reuses the
M1–M4.1 detectors and assigns stable finding IDs.

`SimulationLayer` evaluates the gate at high-risk task acceptance, delegated
child creation, sensitive result delivery, protected tools, and final
aggregation. Observe mode records findings and allows the operation. Enforce
mode records an intervention before the side effect and blocks it. Interaction
records distinguish `attempted`, `completed`, and blocked operations and are
durable in the SQLite `interactions` table.

The executable scenarios include delegation laundering, refusal shopping,
benign collaboration after refusal, legitimate decomposition, and
communication failure. The experimental runner compares conditions A–F; F is
the M4.2 global gate condition. Metrics include attack attempt, detection,
intervention, successful violation, prevention, benign success, false-positive
rate, and unnecessary intervention. This remains an offline deterministic
simulation, not a claim of real-world safety.
