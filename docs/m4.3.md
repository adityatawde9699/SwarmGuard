# M4.3 interaction-engine experiments

`swarmguard experiment-run --suite core` executes the five M4.2 scenarios
through `run_m4_scenario`, under observe and enforce conditions. Each trial
gets a deterministic run ID and a durable SQLite experiment state. The result
JSON includes every gate evaluation in `detection_history`, not only the
eventual finding set, and includes intervention records at the boundary that
made the decision.

The runner emits JSON, CSV, and dependency-free SVG artifacts. Bernoulli
metrics include Wilson 95% intervals; undefined values are `null`. The
evaluator uses objective/task state and event completion independently from
the monitor. This is an offline deterministic experiment and makes no
real-world safety claim.
